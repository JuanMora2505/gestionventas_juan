Proyecto gestionventas - Java 17
Estructura:
- src/co/edu/ean/poo/ventas/... (código fuente)
- data/ (vendedores.csv, ventas.csv)
- output/ (reporte_ventas.txt generado)

Compilación:
javac -d classes src/co/edu/ean/poo/ventas/**/*.java

Ejecución:
java -cp classes co.edu.ean.poo.ventas.App

Menú interactivo en español (usa Scanner).
